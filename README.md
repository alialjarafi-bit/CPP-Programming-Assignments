# CPP-Programming-Assignments
A collection of C++ programming assignments and practical exercises covering basic programming concepts, conditional statements, loops, one-dimensional and two-dimensional arrays, sorting, searching, and mathematical operations. This project is designed to practice and improve programming skills through practical examples


C++ Programming Assignments

A Menu-Driven Collection of C++ Programming Exercises

📌 Project Overview

This project is a console-based C++ application that brings together a collection of programming assignments and exercises in one organized program.

The application uses an interactive menu system that allows users to navigate between different sections and select specific exercises to execute. It provides practical experience with fundamental programming concepts and problem-solving techniques using C++.

The project contains 7 main sections and 85 numbered exercises, organized to make accessing and running individual exercises straightforward.

🎯 Project Objectives

- Practice and strengthen fundamental C++ programming skills.
- Apply programming concepts to practical exercises.
- Improve logical thinking and problem-solving abilities.
- Organize multiple programming assignments within a single application.
- Gain experience with interactive console applications and menu-driven programs.

✨ Key Features

- Interactive Menu System: Navigate between sections and select exercises through numbered options.
- Organized Structure: Exercises are grouped into seven main sections.
- Multiple Programming Exercises: Includes 85 numbered exercise options.
- Practical Implementation: Apply programming concepts through executable C++ code.
- Console-Based Interface: Interact with the application using keyboard input.
- Learning-Oriented Design: Provides a foundation for practicing and improving C++ programming skills.

▶️ How to Run the Project

1. Clone or download this repository.
2. Open the C++ source file in Visual Studio or another compatible C++ IDE.
3. Compile the source code.
4. Run the generated application.
5. Select a section from the main menu.
6. Choose an exercise and follow the instructions displayed in the console.

💻 Example Interaction

The application displays a main menu containing different programming sections.

Users can enter a section number, view its available exercises, and select an exercise to run.

This approach makes it easier to access individual programming tasks without running each exercise as a separate application.
